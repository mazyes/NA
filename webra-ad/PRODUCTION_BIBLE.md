# WEBRA — 30s Brand Spot · Production Bible

**Format:** 9:16 vertical · 1080 × 1920 · 30 fps · 30.00 s · 120 BPM (1 beat = 0.5 s, 1 bar = 2 s)
**Palette:** Ink `#07050C` · Night `#0A0616` · Deep `#140828` · Plum (brand deep purple) `#1D0B3B` · Purple `#5B21B6` · Violet `#8B5CF6` · Lavender `#C4B5FD` · White `#F7F5FF`
**Type:** Display: *Archivo Black* (tracking −20). UI/body: *Inter* 500–800. Labels/URLs: *JetBrains Mono* 500.
**Deliverable in this repo:** `out/webra_30s_1080x1920.mp4` is a finished animatic with the final timing and full sound. You can use it as is, or treat it as the locked reference cut for a Blender/After Effects finish.

> **Logo notice:** the "WEBRA" wordmark in the reveal is placeholder typography set in Archivo Black. It is not the official logo. Replace it with the supplied logo file at the 24.0 s hit. The handle and URL in the call to action are also placeholders (`[ INSTAGRAM HANDLE ]`, `[ WEBSITE URL ]`).

## 1 · Motion language (applies to every shot)

| Rule | Spec |
|---|---|
| Primary ease | Expo-out (in AE: 0 % in, 85–90 % out influence) for all arrivals. Cubic in-out for camera. |
| Overshoot | Back-out with a 2.2 overshoot on pops (UI modules, CTA pill, letters). Use it once per element. Never let an element wobble. |
| Exits | Quint-in (accelerate out) with 20–28° skew for speed. No fades on exits unless the element is masked. |
| Text reveals | Every headline word rises from a hard mask (clip box). It travels 115 % of its cap height in 0.42–0.45 s on expo-out. Words land on the beat or on the next eighth. |
| Tracking | Hero lines settle from +6 to +18 % tracking down to −2 % over about 1 s (slow-motion feel). |
| Depth | Headlines carry a 14–18-step solid extrusion from `#4C1D95` to `#0C0518`. The extrusion angle follows the camera orbit. |
| Cuts | Hard cuts only on downbeats. Every other transition turns one element into the next. |
| Grain | Monochrome grain at 7 % in Overlay mode, re-seeded every frame. Radial vignette to 42 % black at the corners. |

## 5 · Camera, lighting, materials, render

- **Camera:** 50 mm equivalent (CSS perspective 1800 px). Moves:
  - Push-in of 8 % over the hook.
  - 20° orbit plus 280 px dolly-out at 8.0–9.2 s (cubic in-out).
  - Return move at 9.25–9.9 s.
  - Micro-shake only at the crack.
  - Everything else is locked off, so the type stays readable.
- **Lighting:**
  - Key: soft area light from upper-centre (radial falloff `rgba(139,92,246,.20)` at 50 % × 22 %).
  - Bounce: purple from the floor at 50 % × 105 %.
  - Violet rim on the white objects. Glow is limited to the gem and the pulses.
- **Materials:**
  - Phone: black glass (roughness 0.08) and brushed-dark aluminium.
  - UI panels: white satin (roughness 0.35).
  - Primitives: matte plastic.
  - Monolith: purple, roughness 0.6.
  - Zebra: flat emissive white on ink.
- **Blender render:** Cycles, 128 samples plus OIDN, Filmic/AgX "Medium High Contrast", motion blur with 180° shutter. EXR multilayer with AOVs: beauty, shadow, reflection, cryptomatte. Output 1080×1920 at 30 fps.
- **Compositing:** add grain in post, not in render. Keep glows under 20 % opacity (bloom threshold 0.9).

## 7 · Production workflow

**A · Code pipeline (this repo, reproducible):**
```bash
pip install numpy imageio-ffmpeg                    # ffmpeg binary
python3 audio.py                                    # -> audio.wav
export FFMPEG=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
node render.js                                      # -> out/webra_30s_1080x1920.mp4 (Playwright/Chromium)
node render.js --stills 1.9,8.6,24.6                # -> out/stills/*.png for review
```
- To change the handle and URL, edit `HANDLE` and `SITE` at the top of `index.html`, then re-run `node render.js`.
- To preview live with sound, serve the folder (`python3 -m http.server`) and open `index.html`.
- Every element is a pure function of time `t` (`seek(t)`), so renders are frame-exact and repeatable.

**B · Finishing in Blender + After Effects (studio route):**
1. **Lock timing.** Import `out/webra_30s_1080x1920.mp4` and `audio.wav` into AE as the reference layer. Add markers for each cue from section 6.
2. **Blender:** build shots 1c (shatter: Cell Fracture on the screen mesh, rigid body with zero gravity, keyframed impulse), 2d (environment orbit), 3a (gem) and 5b (zebra fold: displace a plane with a zebra texture, Simple Deform bend). Match the camera to the animatic. Render EXR sequences with a cryptomatte pass.
3. **After Effects:**
   - Rebuild all typography as live text: Archivo Black, track-matte masks, and a 14-step extrusion using Repeater or a Shape layer echo.
   - Rebuild UI builds as shape layers with Flow easing presets: expo-out 0.42 s, back-out 2.2.
   - Put the circular wipe on a track-matte ellipse.
4. **Brand:** place the official WEBRA logo (vector) at 24.0 s. Keep the letter-rise mask and the tracking settle.
5. **Finish:**
   - Grain 7 % Overlay, vignette, a light S-curve.
   - Export H.264 High 4.2, 1080×1920, 30 fps, about 12 Mbps, AAC 256k, loudness −14 LUFS integrated.
   - Also export a textless version and a 15 s cut: 0–4 hook, then 22–30 reveal and CTA.
